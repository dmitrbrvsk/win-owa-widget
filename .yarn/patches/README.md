# Локальный патч braces 3.0.3

Русский · [English](README.en.md)

`arui-presets-lint` использует `micromatch`, который зависит от `braces`. Для [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) на 16 октября 2026 года нет опубликованной исправленной версии.

Патч ограничивает глубину стека парсера, рекурсивных обходов compile/expand/stringify и цепочек parent в expand: 128 уровней. Чрезмерная вложенность завершается контролируемой ошибкой вместо переполнения стека или зависания. Лимит распространяется и на скобки, и на круглые скобки; поведение `escapeInvalid` сохранено.

`test/toolingSecurity.test.ts` проверяет все публичные методы, переданный AST и цикл parent в дочернем процессе с таймаутом, а также обычные шаблоны. Без патча тесты не проходят. Yarn закрепляет патч и его checksum в lockfile; `yarn install --immutable` применяет его автоматически.

Только advisory npm ID `1240992` исключен из стандартного отчета аудита, поскольку реестр определяет проблему по версии и не учитывает содержимое локального патча. Другие high/critical проблемы продолжают блокировать CI. Это зависимость инструментов разработки, она не включается в приложение.

После выпуска исправленного upstream-пакета обновите зависимость, удалите патч, resolution и исключение advisory. Регрессионную проверку можно сохранить для новой версии.
