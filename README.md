# OWA Widget для Windows

Встречи из Exchange / OWA в трее Windows: таймлайн дня, подключение к звонку одним нажатием, напоминания и ответы на приглашения. Это Windows-версия [mac-owa-widget](https://github.com/ilyabazhenov/mac-owa-widget), написанная заново на Electron + React + TypeScript.

## Скачать и установить

[**Последний релиз →**](https://github.com/dmitrbrvsk/win-owa-widget/releases/latest): установщик `OWA-Widget-Setup-<версия>.exe` (Windows 10/11 x64; ставится в профиль пользователя, права администратора не нужны; на компьютерах с ARM64 он тоже работает, а родной ARM64-установщик — `OWA-Widget-Setup-<версия>-arm64.exe`) или `OWA-Widget-*-portable-x64.zip` без установки — распакуйте в любую папку и запустите `OWA Widget.exe`.

Приложение живёт в области уведомлений (на Windows 11 иконка может быть под стрелкой «^»). Закрытие окна его не завершает: «Выход» — в меню иконки или в настройках. Новая версия при запуске сама просит старую завершиться. Установщик пока не подписан, поэтому SmartScreen может предупредить. Сверьте контрольную сумму с `SHA256SUMS.txt` из релиза (как это сделать, см. [SECURITY.md](SECURITY.md)) и только потом нажимайте «Подробнее» → «Выполнить в любом случае».

## Возможности

### Календарь и иконка в трее

- **Иконка в трее с обратным отсчётом.** За 15 минут до встречи на иконке число минут, во время встречи — сколько осталось. Жёлтая точка в углу — есть приглашения, на которые вы не ответили. В последние 2 минуты иконка красная; если вы идёте на эту встречу (приняли приглашение или организуете её), она ещё и мигает (закрашенная и контурная попеременно, не дольше 2,5 минут), а когда в Windows выключены анимации, остаётся красной без мигания. Подсказка называет встречу и число приглашений.
- **Окно у трея.** Появляется рядом с иконкой на любом краю экрана. Внутри: ближайшая встреча с кнопкой «Подключиться» (за 30 минут до начала и пока встреча идёт), полоса встреч на весь день, таймлайн с красной линией «сейчас». Пересекающиеся встречи стоят рядом, а не друг на друге.
- **Рабочий день.** Таймлайн показывает только рабочие часы (по умолчанию 08:00–20:00, настраивается); встречи вне этих часов всё равно видны — диапазон расширяется под них.
- **Карточка встречи.** Участники с ответами, полное описание со ссылками, копирование ссылки или «название + время + ссылка». То же даёт правая кнопка мыши на встрече в таймлайне.
- **Поиск по встречам.** Ctrl+F или `/` в окне, Esc закрывает. Ищет по названию, организатору, месту (и категориям) и началу описания; каждое слово запроса должно найтись, «ё» и «е» не различаются. Ищет только среди уже загруженных встреч, на сервер запрос не отправляется и в журнал не пишется.

### Звонки

- **Ссылки на звонки.** Teams, Zoom, Webex, Google Meet и KTalk ищутся в поле онлайн-встречи, в месте и в описании. Если ссылка ведёт на незнакомый сайт, рядом с кнопкой «Подключиться» везде написан её настоящий адрес — и в окне, и в таймлайне, и в поиске, и в уведомлении, и в меню иконки.

### Приглашения и встречи

- **Ответы на приглашения.** «Принять», «Под вопросом», «Отклонить» без Outlook, из окна или прямо из уведомления. Новые приглашения собраны сверху.
- **Создание встречи** с приглашениями, в том числе **повторяющейся**, **изменение и отмена** своей встречи с уведомлением участников, и **поиск свободного времени** по занятости: см. [Создание встречи](#создание-встречи) и [Поиск свободного времени](#поиск-свободного-времени).
- **Статистика встреч** за неделю или за месяц: сколько времени занимают встречи и с кем оно проходит — см. [Статистика встреч](#статистика-встреч).
- **Напоминание** о встрече: уведомление Windows с кнопками или собственное окно над панелью задач (выбирается в настройках). Если встречи начинаются почти одновременно, они показываются вместе.
- **Уведомления об изменениях:** «Встречу перенесли», «Встречу отменили», «Новое приглашение». Не больше шести в час; если сразу меняется много встреч (например, правят серию), приходит одно общее уведомление.

### Вход, безопасность, оформление

- **Вход.** Если логин и пароль не указаны — под учётной записью Windows (Kerberos / NTLM, пароль не нужен); если указаны — по ним: NTLM, а для старых серверов — форма входа OWA. В поле адреса нужен сервер OWA (тот, что в адресной строке браузера, например `mail.company.ru`), а не адрес почты; по умолчанию подставлен `owa.alfabank.ru`, при первом запуске открываются настройки, где его можно заменить.
- **Безопасность.** Пароль шифруется Windows (DPAPI), привязан к вашему серверу и уходит только на него. Только HTTPS, перенаправления на другой хост или порт обрываются. Смена сервера подтверждается в системном окне. Сертификаты проверяются по хранилищу Windows; внутреннему сертификату можно довериться только в системном окне с отпечатком. Кеш встреч зашифрован. Ссылки открываются только `http(s)`. Подробности: раздел [Безопасность](#безопасность) и [SECURITY.md](SECURITY.md).
- **Знакомство при первом запуске** — четыре шага о том, где живёт иконка, как подключиться и что умеет приложение. Показывается один раз, пропускается в один клик, потом открывается из настроек.
- Светлая и тёмная темы, русский и английский, автозапуск при входе в Windows, три размера окна.

Подробнее о крупных функциях — ниже.

### Создание встречи

Открыть: кнопка «+» в окне у трея, пункт «Создать встречу…» в меню иконки или кнопка «Создать встречу на это время» в окне поиска свободного времени (время подставится само).

- **Участники.** «Обязательные» и «Необязательные». Начните вводить имя или адрес: подсказки приходят из адресной книги Exchange. Адрес можно вставить целиком, списком через запятую, точку с запятой или с новой строки. Принимаются только обычные адреса из латинских букв и цифр: адрес с «похожими» кириллическими буквами отклоняется, чтобы приглашение не ушло подставному адресату.
- **Время.** Дата и время начала и конца, быстрый выбор длительности (30 / 45 минут, 1 час). Время уходит на сервер как точный момент, поэтому переход на летнее время ничего не сдвигает.
- **Подтверждение.** Если у встречи есть участники, перед отправкой Windows показывает **системное окно** с темой, временем, местом, началом описания и списком получателей (первые 15 и «и ещё N»). Оно строится из тех данных, которые уйдут на сервер, и по умолчанию отвечает «Отмена». Окно создания встречи это окно нажать не может: даже скомпрометированная страница интерфейса не способна разослать приглашения. Встреча без участников только сохраняется в вашем календаре, подтверждение для неё не нужно.
- **Ограничения.** За час отправляется не больше 10 встреч и 300 приглашённых; одновременно одна встреча; не больше 12 запросов на подтверждение за 10 минут. Это защита от случайного цикла и от «залипшей» страницы.
- **Если ответ сервера не дошёл** (оборвалась связь), приложение не повторяет отправку само: повтор мог бы разослать всем второе приглашение. Оно просит сначала посмотреть календарь.
- **Повторяющаяся встреча.** «Каждый день», «Каждый будний день», «Каждую неделю», «Каждые две недели», с окончанием по числу повторений (не больше 100) или по дате (не дальше двух лет). Сколько будет повторений, написано в окне подтверждения: пятьдесят приглашений нельзя отправить, не увидев этого.
- **Изменение своей встречи.** В карточке встречи, которую вы организуете, есть «Изменить»: открывается то же окно, заполненное тем, что уже есть. На сервер уходят только изменённые поля, участники узнают об изменении, а в окне подтверждения показано, что именно меняется — включая старое и новое время и тех, кого добавили или убрали.
- **Отмена своей встречи.** Кнопка «Отменить встречу» в карточке: всем приглашённым уходит уведомление об отмене. Подтверждение прямо говорит, скольким людям оно уйдёт и что вернуть встречу нельзя. Безопасный ответ («Не отменять») выбран по умолчанию.
- **Не проверено на настоящем Exchange.** Запросы `CreateItem`, `UpdateItem`, `CancelCalendarItem` и `ResolveNames` написаны по документации EWS и проверены на поддельном сервере и модульными тестами. Первую встречу попробуйте сначала без участников или только с собой.

### Поиск свободного времени

Открыть: кнопка с календарём в окне у трея или пункт «Найти свободное время…» в меню иконки.

- Укажите до 20 участников (адреса или имена из адресной книги) и длительность (30 / 45 / 60 / 90 минут). Сетка показывает занятость по 30 минут в рабочие часы (часы и дни недели — из настроек), неделя листается стрелками, «Выходные» включают субботу и воскресенье.
- Цвета: «Свободен», «Под вопросом», «Занят», «Нет на месте», «Нет данных» (нет доступа к календарю человека или сервер не ответил). Название чужой встречи видно только там, где Exchange разрешил его показать вам.
- «Лучшие варианты» — до пяти промежутков нужной длительности, когда никто не занят и не «вне офиса». «Под вопросом» не мешает, но снижает оценку и отмечается; человек без данных тоже не мешает, но вариант помечается как менее надёжный (если данных нет ни у кого, вариантов нет). Чем раньше и чем ближе к началу часа, тем выше; обед и выходные понижаются; прошедшее время не предлагается; не больше двух вариантов на день. Выбранный вариант подсвечивается в сетке, а кнопка «Создать встречу на это время» открывает окно создания с уже заполненными временем и участниками.
- Свою занятость приложение берёт с сервера по адресу вашего ящика; если сервер его не сообщил, используется календарь, уже загруженный в виджет, и под сеткой есть подпись об этом.
- Запрос идёт только на настроенный сервер Exchange (`GetUserAvailability`); окно запрашивает не больше 20 адресов и не больше 14 дней за раз, ответы разбираются с ограничениями по размеру и времени.
- **Не проверено на настоящем Exchange:** запрос написан по документации EWS и проверен на поддельном сервере и модульными тестами.

### Статистика встреч

Открыть: кнопка с диаграммой в окне у трея или пункт «Статистика встреч…» в меню иконки.

- **Период:** «Эта неделя», «Прошлая неделя», «Последние 4 недели» (недели считаются с понедельника; рядом написано, какие это даты).
- **Сверху — главные числа:** всего времени во встречах, доля рабочего времени (рабочие часы — из настроек), число встреч, средняя длительность, самый плотный день, сколько встреч шли подряд (начинались в тот момент, когда заканчивалась другая), сколько рабочего времени осталось свободным. Встречи, идущие одновременно, в «занятом времени» считаются один раз, поэтому доля не бывает больше 100%.
- **Диаграмма по дням** — часы встреч в каждом дне периода, обычным HTML, без сторонних библиотек. Встреча через полночь делится между двумя днями, встреча, выходящая за период, считается только своей частью внутри него.
- **«С кем чаще всего»** — по часам и по числу встреч. Считается организатор встречи: списки участников виджет не запрашивает (это был бы отдельный запрос на каждую встречу), поэтому встречи один на один по участникам не учитываются, и об этом написано в самом окне. Встречи, которые организуете вы, показаны отдельной строкой: другого организатора у них нет.
- **Разбивка по платформам** (Teams, Zoom, Webex, Google Meet, KTalk, другая ссылка, без ссылки) и **по вашему ответу** (принял, под вопросом, организатор, без ответа).
- **Что не считается:** отменённые встречи (в том числе с префиксом «Отменено:») и те, от которых вы отказались. Записи на весь день считаются днями, а не часами, — иначе неделя дежурства выглядела бы как 168 часов встреч.
- **Откуда данные.** В памяти виджет держит только 7 дней назад и 30 вперёд, поэтому встречи за период запрашиваются у сервера отдельно — одним запросом `GetCalendarView`, тем же, что и обычная синхронизация. Период проверяется до запроса: не длиннее 60 дней и не дальше двух лет от сегодняшнего дня; одновременно идёт один запрос, не больше 20 за 10 минут. Ничего другого на сервер не уходит, и никуда больше данные не отправляются. Ответ не попадает в кэш и не подменяет синхронизированный список: он живёт только в этом окне.
- Все вычисления — в `src/shared/stats.ts`, без Electron и React, и покрыты тестами (`test/stats.test.ts`).

### Уведомления

Напоминания и сообщения об изменениях показываются как уведомления Windows. Кнопки в них нажимаются без открытия окна приложения.

| Уведомление | Что в нём |
|---|---|
| Напоминание о встрече | Заголовок «Встреча через N мин», название, время и организатор. Выпадающий список «Отложить на 5 / 10 / 15 минут», кнопки «Подключиться» (для ссылки на незнакомый сайт рядом виден её хост) и «Отложить». Если встреч несколько, вместо «Подключиться» кнопка «Открыть». Не пропадает, пока вы не отреагируете. |
| Новое приглашение | Кто приглашает, на что и когда. Кнопка «Принять»; щелчок по тексту открывает встречу в окне. |
| Встречу перенесли или отменили | Что и на когда. Щелчок по тексту открывает встречу в окне. |

Как это устроено и где граница:

- **Настройка «Как показывать напоминание».** «Автоматически» включает уведомление Windows только для установленной копии (у неё есть ярлык в меню «Пуск», без которого Windows не доставляет уведомления приложения). Из portable-архива в этом режиме показывается собственное окно напоминания, которое видно всегда. «Уведомление Windows» и «Окно приложения» включают нужный вариант принудительно.
- Если система сообщила об ошибке показа уведомления, приложение само открывает собственное окно напоминания. Когда Windows молча убирает уведомление в центр уведомлений (см. ниже), приложение этого увидеть не может.
- Режимы «Не беспокоить» и «Помощник по фокусировке» Windows могут держать уведомления в центре уведомлений: это поведение системы. Если важно не пропускать встречи, выберите «Окно приложения».
- Кнопки работают, пока приложение запущено. Уведомление, оставшееся в центре уведомлений после выхода из приложения, при нажатии просто запустит приложение.
- В журнале пишутся только счётчики («toast: handed to Windows», «changes: 2 new»), без названий встреч.
- **Не проверено на настоящем Windows.** Уведомления с кнопками и выпадающим списком написаны по документации Electron 44 и проверены модульными тестами логики (какая кнопка что делает), но не проверены глазами на живой системе: в среде разработки Windows нет. Первым делом проверьте на установщике; если что-то выглядит или работает не так, выберите «Окно приложения» и напишите, что именно не так.

## F.A.Q.

### Общие вопросы

<details>
<summary><b>Что это и чем отличается от Outlook?</b></summary>

Небольшое приложение в области уведомлений Windows: показывает встречи из вашего Exchange (через веб-интерфейс OWA), напоминает о них, подключает к звонку одним нажатием, отвечает на приглашения, создаёт встречи и ищет свободное время. Почту оно не читает, только календарь. Outlook оно не заменяет: это быстрый доступ к тому, что нужно в течение дня.
</details>

<details>
<summary><b>Какие серверы поддерживаются?</b></summary>

Рассчитано на корпоративный (локальный, on-premises) Exchange с веб-доступом OWA: вход по форме OWA или встроенный вход Windows (Kerberos / NTLM). Не поддерживаются и не проверялись: Exchange Online (Microsoft 365) и вход через отдельный портал единого входа (ADFS, Azure AD и подобные). В этом случае приложение остановится и объяснит, куда его перенаправили. Создание встреч, поиск людей и поиск свободного времени написаны по документации EWS и пока не проверены на настоящем Exchange: первую встречу создайте без участников или только с собой.
</details>

<details>
<summary><b>Можно подключить Google Календарь, iCloud или несколько аккаунтов Exchange?</b></summary>

Пока нет: один аккаунт Exchange. 
</details>

<details>
<summary><b>Сколько приложение занимает памяти?</b></summary>

Около 70–90 МБ в покое и 130–150 МБ с открытым окном виджета на Windows: это Electron, то есть встроенный Chromium. Подробности — в разделе [Память](#память).
</details>

### Вход и данные

<details>
<summary><b>Какой адрес сервера указывать?</b></summary>

Адрес OWA, как в адресной строке браузера, например `mail.company.ru`. Адрес почты (`имя@company.ru`) не подходит: приложение отклонит его сразу. По умолчанию подставлен `owa.alfabank.ru`, при первом запуске открываются настройки, где его можно заменить.
</details>

<details>
<summary><b>Нужны ли логин и пароль?</b></summary>

Не обязательно. Если оставить оба поля пустыми, приложение входит под вашей учётной записью Windows (Kerberos / NTLM). Если указаны, входит по ним, в том виде, в каком вы входите в OWA (например, `ДОМЕН\логин`). После неверного пароля приложение делает одну попытку и останавливает синхронизацию до смены настроек, чтобы доменная учётная запись не заблокировалась.
</details>

<details>
<summary><b>Куда уходят мои данные? Есть ли телеметрия?</b></summary>

Только на сервер Exchange, который вы указали в настройках. Телеметрии, автообновления и сторонних сервисов нет, а страницам интерфейса сетевые соединения запрещены. Подсказки людей, занятость участников, встречи за период для статистики, созданные встречи и ответы на приглашения тоже идут только на этот сервер. Поиск по встречам работает локально. Подробнее — в разделе [Безопасность](#безопасность) и в [SECURITY.md](SECURITY.md).
</details>

<details>
<summary><b>Где хранится пароль?</b></summary>

В вашем профиле Windows, зашифрованным средствами системы (DPAPI), вместе с адресом сервера, для которого он введён: на другой сервер приложение пароль не отдаст. Если шифрование недоступно, пароль не сохраняется вообще. Кэш встреч шифруется так же.
</details>

### Установка и обновление

<details>
<summary><b>Windows SmartScreen предупреждает об установщике. Это нормально?</b></summary>

Пока да: установщик не подписан сертификатом Authenticode. Скачивайте только со страницы [Releases](https://github.com/dmitrbrvsk/win-owa-widget/releases) этого репозитория, сверьте контрольную сумму файла с `SHA256SUMS.txt` (команды — в [SECURITY.md](SECURITY.md)) и только потом нажимайте «Подробнее» → «Выполнить в любом случае».
</details>

<details>
<summary><b>Установщик или portable-архив?</b></summary>

Установщик (`OWA-Widget-Setup-*.exe`) ставится в профиль без прав администратора, создаёт ярлык в меню «Пуск» (без него Windows не показывает уведомления приложения) и удаляется через «Параметры → Приложения». Portable (`OWA-Widget-*-portable-x64.zip`) просто распаковывается и запускается; уведомления Windows из него не гарантируются, поэтому в режиме «Автоматически» напоминания показываются собственным окном приложения.
</details>

<details>
<summary><b>Как обновить приложение?</b></summary>

Автообновления нет. Скачайте новую версию и запустите установщик поверх старой (настройки и пароль сохраняются) или распакуйте новый portable-архив: запущенная старая версия завершится сама.
</details>

<details>
<summary><b>Как удалить приложение и свои данные?</b></summary>

Установленную копию удалите через «Параметры → Приложения»: установщик сотрёт настройки, зашифрованный пароль, кэш и журнал. Portable: закройте приложение («Выход» в меню иконки), удалите папку с ним и папку `%APPDATA%\OWA Widget`.
</details>

<details>
<summary><b>Как снова открыть знакомство с приложением?</b></summary>

Настройки → Диагностика → «Показать знакомство с приложением». Само оно открывается только при самом первом запуске; после обновления не появляется.
</details>

<details>
<summary><b>Я закрыл окно, а приложение осталось. Как выйти? Как отключить автозапуск?</b></summary>

Закрытие окна приложение не завершает: оно живёт в области уведомлений (в Windows 11 иконка может быть под стрелкой «^»). Выйти можно через «Выход» в меню иконки (правая кнопка) или в настройках. Автозапуск включается и выключается там же: «Запускать при входе в Windows».
</details>

### Окно, иконка и встречи

<details>
<summary><b>Что значит иконка в трее?</b></summary>

Календарь без числа: встреч нет или до ближайшей больше 15 минут. Синяя с числом: до встречи не больше 15 минут. Зелёная с числом: встреча идёт, осталось столько минут. Красная: до начала меньше двух минут; если вы идёте на эту встречу, иконка ещё и мигает. Жёлтая точка в углу: есть приглашения, на которые вы не ответили. Подсказка при наведении называет встречу и число непринятых приглашений. Все состояния — на снимке «Иконка в трее» выше.
</details>

<details>
<summary><b>Как найти встречу?</b></summary>

Ctrl+F или `/` в окне у иконки. Ищет по названию, организатору, месту и началу описания среди загруженных встреч; все слова запроса должны найтись. Esc закрывает поиск.
</details>

<details>
<summary><b>Как скопировать название или ссылку встречи?</b></summary>

Правая кнопка мыши на встрече в таймлайне открывает меню: «Копировать название», «Копировать ссылку» (если она есть) и «Копировать название, время и ссылку». То же есть в карточке встречи.
</details>

### Создание встречи и свободное время

<details>
<summary><b>Как создать встречу и что произойдёт с приглашениями?</b></summary>

Нажмите «+» в окне у иконки или выберите «Создать встречу…» в меню иконки. Укажите тему, время и участников (подсказки приходят из адресной книги Exchange). Если участники есть, перед отправкой Windows покажет окно со списком получателей: приглашения уйдут от вашего имени только после нажатия «Отправить», а «Отмена» стоит по умолчанию. Встреча без участников сохраняется только в вашем календаре. Подробности и ограничения — в разделе [Создание встречи](#создание-встречи).
</details>

<details>
<summary><b>Можно ли перенести или отменить встречу?</b></summary>

Да, если вы её организуете: откройте карточку встречи — там есть «Изменить» и «Отменить встречу». И то и другое спрашивает подтверждение в окне Windows и показывает, что именно изменится и скольким людям об этом сообщат. Чужую встречу изменить нельзя — у организатора нет такого разрешения для вас.
</details>

<details>
<summary><b>Можно ли сделать встречу повторяющейся?</b></summary>

При создании: «Повторять» → каждый день, каждый будний день, каждую неделю или каждые две недели, с окончанием по числу повторений или по дате. Изменить уже существующую серию можно только целиком, и приложение об этом предупреждает.
</details>

<details>
<summary><b>Почему перед отправкой приглашений появляется окно Windows, а не кнопка в самом приложении?</b></summary>

Это защита: окно рисует система, и страница интерфейса нажать его не может. Даже если бы окно приложения оказалось скомпрометировано, оно не смогло бы разослать приглашения без вашего ответа. В окне показано ровно то, что будет отправлено.
</details>

<details>
<summary><b>Не пришёл ответ после «Отправить». Нажимать ещё раз?</b></summary>

Сначала посмотрите свой календарь и «Отправленные» в OWA. Если связь оборвалась, пока ответ был в пути, встреча могла быть создана, а приложение намеренно не повторяет отправку само, чтобы не разослать всем второе приглашение.
</details>

<details>
<summary><b>Почему у человека в сетке «Нет данных»?</b></summary>

Exchange не отдал вам его календарь: нет разрешения на просмотр занятости, адрес не найден или сервер не ответил. Такой человек не мешает «лучшим вариантам», но вариант помечается как менее надёжный. Названия чужих встреч показываются только там, где Exchange разрешил.
</details>

### Уведомления и неполадки

<details>
<summary><b>Напоминание не появилось. Что проверить?</b></summary>

Режимы «Не беспокоить» и «Помощник по фокусировке» Windows могут держать уведомления в центре уведомлений. Из portable-архива в режиме «Автоматически» напоминание показывается собственным окном. Если важно не пропускать встречи, выберите в настройках «Окно приложения». Подробнее — в разделе [Уведомления](#уведомления).
</details>

<details>
<summary><b>Календарь пуст или показывает странное. Что делать?</b></summary>

Откройте Настройки → Диагностика → «Сбросить кэш»: приложение забудет сохранённый список встреч и сеанс и загрузит всё заново (пароль и настройки останутся). Приложение показывает ваш основной календарь. Если не помогло, посмотрите журнал (следующий вопрос).
</details>

<details>
<summary><b>Где журнал и что в нём?</b></summary>

Настройки → Диагностика → «Открыть папку с журналом» (`%APPDATA%\OWA Widget\logs\owa-widget.log`, до 1 МБ). В нём адреса запросов без параметров, коды ответов, ошибки и счётчики. Паролей, cookie, названий и содержимого встреч, текстов запросов и адресов получателей в нём нет, его безопасно приложить к issue.
</details>

<details>
<summary><b>Как сообщить об ошибке или уязвимости?</b></summary>

Об ошибке — в [Issues](https://github.com/dmitrbrvsk/win-owa-widget/issues) (приложите журнал, если он есть, и версию из подвала окна). Об уязвимости — не в открытых issues, а через [Security → Report a vulnerability](https://github.com/dmitrbrvsk/win-owa-widget/security/advisories/new).
</details>

## Если что-то не работает

- **«Сертификат сервера не прошёл проверку».** Приложение проверяет сертификат по хранилищу Windows, как Edge. Сообщение говорит, почему именно он не прошёл (неизвестный центр сертификации, другое имя, просрочен) и кем выдан. Если это внутренний сертификат компании, правильнее установить корневой сертификат компании в Windows; если это невозможно, нажмите «Доверять сертификату» — приложение запомнит отпечаток для этого сервера и покажет системное окно с подтверждением.
- **«По адресу … нет OWA (HTTP 404)»** или **«не похожа на Outlook Web App».** Проверьте адрес: это должен быть сервер OWA, а не адрес почты и не сайт компании.
- **«Сервер перенаправляет вход на …».** Вход идёт через другой портал (единый вход). Пока не поддерживается; попробуйте оставить логин и пароль пустыми, чтобы войти под учётной записью Windows.
- **Календарь показывает устаревшее или странное.** Настройки → Диагностика → «Сбросить кэш»: список встреч и сеанс на сервере забываются и загружаются заново. Пароль и настройки не затрагиваются.
- **После смены адреса сервера пропал пароль.** Так и задумано: пароль привязан к серверу, для которого вы его ввели, и на другой сервер не переносится. Введите его заново.
- **«Нет связи с сервером Exchange (ERR_…)».** В скобках стоит причина, которую сообщил сетевой слой Windows: `ERR_HTTP2_PROTOCOL_ERROR` или `ERR_EMPTY_RESPONSE` обычно значит, что запрос не пропускает шлюз или прокси, `ERR_CONNECTION_*` — что сервер недоступен (проверьте VPN). Эту же строку, вместе с адресом запроса, пишет журнал.
- **После неверного пароля ничего не обновляется.** Так и задумано: приложение делает одну попытку входа и больше не повторяет её, пока вы не измените настройки, — иначе несколько нажатий «Обновить» заблокировали бы доменную учётную запись. Введите пароль заново в настройках.
- **Напоминание не появилось.** Проверьте режимы «Не беспокоить» и «Помощник по фокусировке» в Windows или выберите в настройках «Окно приложения».
- **Окно пустое или ошибка без объяснений.** Откройте Настройки → Диагностика → «Открыть папку с журналом». В журнале адреса запросов, коды ответов и ошибки; паролей, cookie и содержимого встреч там нет. Его можно приложить к issue.

## Безопасность

Приложение рассчитано на то, что ему доверяют пароль от корпоративной почты, поэтому устроено строго. Главное:

- **Только ваш сервер.** Все запросы идут на адрес Exchange из настроек, только по https и только на тот же хост и порт (в том числе при перенаправлениях). Телеметрии, автообновления и сторонних сервисов нет; страницам интерфейса сетевые соединения запрещены.
- **Пароль** шифруется Windows (DPAPI), привязан к серверу и на другой не отдаётся. Смена сервера, доверие внутреннему сертификату и отправка приглашений подтверждаются в **системных окнах**, которые страница интерфейса нажать не может.
- **Недоверенный текст.** Названия, описания, ссылки и ответы сервера разбираются за линейное время, с ограничениями размера, и очищаются; ссылки открываются только как `http(s)`, а у незнакомых сайтов виден настоящий хост.
- **Сборка проверяема.** Установщик не подписан сертификатом, но у каждого `.exe` есть контрольная сумма и подтверждение происхождения: оно доказывает, что файл собран из этого репозитория в GitHub Actions.

Полное описание, проверка скачанного файла, известные ограничения и как сообщить об уязвимости — в [SECURITY.md](SECURITY.md).

## Память

Это Electron, то есть встроенный Chromium. В покое работают два процесса (главный с Node.js и сетевой сервис), около 70–90 МБ на Windows: иконку в трее рисует сам главный процесс, а окно у трея создаётся по щелчку и освобождается через три минуты после того, как его закрыли (пока оно открыто, добавляется ещё около 60 МБ). GPU-процесс отключён: виджету нечего ускорять, а это ещё один процесс и 30–40 МБ. Окна настроек, «Создать встречу», «Свободное время», «Статистика встреч» и напоминание создаются по требованию и освобождаются при закрытии (каждое открытое окно — это ещё примерно 100 МБ); уведомления Windows окон не создают.

## Для разработчиков

### Запуск

```bash
npm install
npm run dev:demo     # вымышленные встречи, Exchange не нужен
npm run dev          # с настоящим аккаунтом
npm test             # тесты разбора OWA, логики встреч, уведомлений и защит
npm run dist         # установщик и portable .zip в release/ (на Windows)
```

Тест-кейсы для ручного тестирования: [docs/TEST-CASES.md](docs/TEST-CASES.md) — 142 проверки по всем экранам, с предусловиями, шагами и ожидаемым результатом.

Сборка `.exe` запускается в GitHub Actions на `windows-latest`. Чтобы выпустить релиз, поднимите `version` в `package.json` и запушьте в `master`: релиз `v<версия>` создастся сам.

### Как устроено

| Папка | Что делает |
|---|---|
| `src/main/owa/` | Клиент OWA: вход, `GetCalendarView`, `GetCalendarEvent`, ответы на приглашения, создание встреч (`CreateItem`), поиск людей (`ResolveNames`), занятость (`GetUserAvailability`) через EWS; разбор XML (`xml.ts`). Работает на сетевом стеке Chromium, поэтому SSO, прокси и сертификаты Windows подхватываются сами. |
| `src/main/` | Трей и его пульсация (`trayPulse.ts`), окна, синхронизация, напоминания, уведомления (`toasts.ts`), «ворота» создания встреч с подтверждением и лимитами (`meetingGate.ts`), хранение настроек и пароля. |
| `src/shared/` | Логика без привязки к Electron: поиск ссылок, раскладка таймлайна, статус трея, сравнение списков встреч (`changes.ts`), тексты и кнопки уведомлений (`toasts.ts`), привязка пароля к серверу (`secret.ts`), поиск по встречам (`search.ts`), сетка занятости и «лучшие варианты» (`availability.ts`), арифметика статистики встреч (`stats.ts`), проверка адресов (`email.ts`), текст подтверждения встречи (`meetingConfirm.ts`). Покрыта тестами. |
| `src/renderer/` | Интерфейс на React. В обычном браузере работает на демо-данных (`npm run build:renderer`). |
