Установка и подключение

  1. Скачайте сборку

    На странице релиза выберите установщик x64 или ARM64. Чтобы запустить без установки, возьмите portable-архив x64.

  2. Откройте виджет

    Запустите приложение и найдите его значок рядом с часами. В Windows 11 он может быть под стрелкой «^».

  3. Подключите календарь

    В настройках укажите адрес корпоративного OWA, например mail.company.ru, и войдите в свою учетную запись.

Частые вопросы

Совместимость, подключение и данные календаря.

Какой Exchange подходит?

Нужен корпоративный Exchange с Outlook Web App. Поддерживаются встроенный вход Windows (Kerberos / NTLM) и форма OWA. Exchange Online, Microsoft 365, OAuth и отдельные SSO-порталы не поддерживаются.

Нужен ли VPN?

Если сервер OWA доступен только из корпоративной сети, подключите VPN перед входом. Поиск занятости и создание встреч также требуют доступа к EWS.

Что происходит с данными календаря?

Приложение обращается к указанному серверу Exchange по HTTPS. Пароль, локальный кеш и заметки хранятся зашифрованными. Подробнее о безопасности.

Как скрыть данные при демонстрации экрана?

Включите режим приватности кнопкой с замком. Виджет скроет названия встреч, имена, адреса и заметки и оставит время и занятость. Этот режим можно попробовать прямо в демо.
