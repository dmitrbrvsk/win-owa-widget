# README media

[Русский](README.md) | English

The new version 1.3.0 demonstrations were captured on October 15, 2026, in the existing React interface's browser demo mode. Product code was not changed for the recording. The images retain the Russian interface labels.

- `hero.png` — a composition of two actual interface screenshots in light and dark themes.
- `day-to-call.gif` — the schedule, search, meeting card and join button. Joining a call is not demonstrated.
- `find-a-time.gif` — selecting the saved "My team" group, loading three attendees' availability, setting a 45-minute duration and choosing a shared free time slot.
- `privacy-mode.gif` — the normal widget, enabling privacy while retaining times and availability, then returning to the normal view.
- `availability-light.png` — the final frame of the new find-a-time scenario.
- `settings-connection-light.png` — four diagnostic stages. In demo mode they are marked "Not checked": no network connection is made.
- `settings-updates-light.png` — manual update checking and the safe support report. The demo API supplies the version-check result without a GitHub request.
- `calendar-light.png` — the separate larger window introduced in version 1.4.0, with the schedule and selected meeting side by side; captured in the browser demo.
- `stats-light.png` — the actual meeting statistics screen with fictional data for a week: totals, a daily chart, organizers and platforms. Replaces a meeting-creation screenshot that had been included here by mistake.
- The remaining PNG files illustrate the main calendar and invitation scenarios.

All meetings and attendees are fictional. Groups in the browser demo exist only in memory. Recording does not contact Exchange, check credentials or send invitations. The new GIF files combine consecutive screenshots of actual interface states and loop; delays allow time to read the screen. These screenshots do not show Electron's main process, the tray or native confirmation dialogs. Fonts and Windows system styling may differ.

The original gallery is preserved in `../screenshots/` and is available from the [English user guide](../GUIDE.en.md).
