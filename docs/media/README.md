# Материалы для README

Новые демонстрации версии 1.3.0 сняты 15 октября 2026 года в браузерном демо-режиме существующего React-интерфейса. Продуктовый код для съемки не изменен.

- `hero.png` — композиция двух настоящих снимков интерфейса, светлая и темная темы.
- `day-to-call.gif` — расписание, поиск, карточка встречи и кнопка подключения. Вход в звонок не демонстрируется.
- `find-a-time.gif` — выбор сохраненной группы «Моя команда», загрузка занятости трех участников, длительность 45 минут и выбор общего свободного интервала.
- `privacy-mode.gif` — обычный виджет, включение приватности с сохранением времени и занятости, возврат к обычному виду.
- `availability-light.png` — итоговый кадр нового сценария поиска времени.
- `settings-connection-light.png` — четыре этапа диагностики. В демо они помечены «Не проверялось»: сетевого подключения нет.
- `settings-updates-light.png` — ручная проверка обновлений и безопасный отчет для поддержки. Результат проверки версии дает демо API без запроса GitHub.
- `calendar-light.png` — отдельное большое окно версии 1.4.0, расписание и выбранная встреча рядом; снимок браузерного демо.
- Остальные PNG иллюстрируют основные сценарии календаря и приглашений.

Все встречи и участники вымышлены. Группы в браузерном демо живут только в памяти. Съемка не обращается к Exchange, не проверяет учетные данные и не отправляет приглашения. Новые GIF собраны из последовательных снимков настоящих состояний интерфейса и зациклены; задержки дают время прочитать экран. Главный процесс Electron, трей и системные подтверждения на этих снимках не показаны. Шрифты и системное оформление Windows могут отличаться.

Исходная галерея сохранена в `../screenshots/` и доступна из руководства.
