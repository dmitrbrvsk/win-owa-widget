# Материалы для README

Съемка: 15 октября 2026 года, 11:00, Europe/Moscow. Использован браузерный демо-режим существующего React-интерфейса; продуктовый код не изменен.

- `hero.png` — композиция двух настоящих снимков интерфейса, светлая и темная темы.
- `day-to-call.gif` — расписание, поиск, карточка встречи и кнопка подключения. Вход в звонок не демонстрируется.
- `find-a-time.gif` — участники, длительность, выбор интервала и форма создания встречи.
- Остальные PNG — неподвижные кадры для просмотра без анимации и иллюстрации сценариев.

Все данные вымышлены. Браузерный стенд передает выбранное время и участников из демо API в форму создания встречи; он не обращается к Exchange и не отправляет приглашения. В стенде версия снимка приведена к версии package.json. Главный процесс Electron, трей и системные подтверждения на этих снимках не показаны. Шрифты и системное оформление Windows могут отличаться.

Исходная галерея сохранена в `../screenshots/` и доступна из руководства. GIF зациклены, подписи включены в кадры.
