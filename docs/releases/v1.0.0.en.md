## Included in this release

- **Your schedule at hand.** A daily timeline, the next meeting, new invitations and one-click access to calls.
- **Meeting creation.** Set the title, time, location, description and attendees, with suggestions from the Exchange address book. Invitations are sent after confirmation in a native dialog.
- **Find a time together.** View attendees' availability, choose a duration and select suitable time slots that carry over to meeting creation.
- **Local search.** Press `Ctrl+F` or `/` to search loaded meetings by title, organizer, location and description.
- **Copy menu.** Right-click a meeting to copy its title, its link, or the title together with the time and link.
- **Tray icon and reminders.** A countdown to the next meeting, an indicator for unanswered invitations, a pulse before the start, and Windows notifications or the app's own reminder window.
- **First-run introduction.** Four short steps explain where to find the widget and how to connect it. Light and dark themes and Russian and English interfaces are available.

### Reliability improvements

An invitation response is considered sent only after explicit confirmation from Exchange. If the connection fails while creating a meeting, the app warns that the result is uncertain and does not resend automatically, to avoid duplicates.

## Installation

- **OWA-Widget-Setup-1.0.0.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Installs for the current user; administrator rights are not required.
- **OWA-Widget-1.0.0-portable-x64.zip** — no installation: extract to any folder and run `OWA Widget.exe`. Nothing is written to temporary folders.

## Verify the file's authenticity

The installer is not yet signed with a Windows certificate, so SmartScreen may display "Windows protected your PC". Before clicking "Run anyway", verify the file:

- **Checksum.** In PowerShell: `Get-FileHash .\OWA-Widget-Setup-1.0.0.exe -Algorithm SHA256` — the result must match the corresponding line in this release's `SHA256SUMS.txt`.
- **Build provenance.** `gh attestation verify .\OWA-Widget-Setup-1.0.0.exe --repo dmitrbrvsk/win-owa-widget` confirms that the file was built from this repository by a GitHub Actions workflow.
