**Calendar statistics, recurring meetings, editing and cancellation.**

**Download:** [x64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.1.0/OWA-Widget-Setup-1.1.0.exe) · ARM64 — x64 under emulation · [Portable](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.1.0/OWA-Widget-1.1.0-portable-x64.zip)

## Changes

- **Meeting statistics.** A new screen shows hours spent in meetings, the share of working time, daily workload, frequent organizers and call platforms. It covers the current week, the previous week and the last four weeks.
- **Edit your meetings.** Change the title, time, location, description and attendees. Before sending, a native Windows dialog shows what will change and who will receive a notification.
- **Cancel your meetings.** A separate action in the meeting card cancels the meeting, with attendee notifications and confirmation before sending.
- **Recurring meetings.** When creating a meeting, repeat it daily, on weekdays, weekly or every two weeks. End the series on a date or after a number of occurrences.

### Important

You can edit and cancel only meetings you organize. Changes to a recurring series apply to the whole series. Statistics count overlapping time slots once when calculating busy time.

## Installation

- **OWA-Widget-Setup-1.1.0.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Installs for the current user; administrator rights are not required.
- **OWA-Widget-1.1.0-portable-x64.zip** — no installation: extract to any folder and run `OWA Widget.exe`. Nothing is written to temporary folders.

## Verify the file's authenticity

The installer is not yet signed with a Windows certificate, so SmartScreen may display "Windows protected your PC". Before clicking "Run anyway", verify the file:

- **Checksum.** In PowerShell: `Get-FileHash .\OWA-Widget-Setup-1.1.0.exe -Algorithm SHA256` — the result must match the corresponding line in this release's `SHA256SUMS.txt`.
- **Build provenance.** `gh attestation verify .\OWA-Widget-Setup-1.1.0.exe --repo dmitrbrvsk/win-owa-widget` confirms that the file was built from this repository by a GitHub Actions workflow.
