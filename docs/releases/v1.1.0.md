**Статистика календаря, повторяющиеся встречи, редактирование и отмена.**

**Скачать:** [x64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.1.0/OWA-Widget-Setup-1.1.0.exe) · ARM64 — x64 в эмуляции · [Portable](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.1.0/OWA-Widget-1.1.0-portable-x64.zip)

## Что изменилось

- **Статистика встреч.** Новый экран показывает часы во встречах, долю рабочего времени, загруженность по дням, частых организаторов и платформы звонков. Доступны текущая неделя, прошлая неделя и последние четыре недели.
- **Редактирование своих встреч.** Можно изменить тему, время, место, описание и состав участников. Перед отправкой системное окно показывает, что именно изменится и кому уйдет уведомление.
- **Отмена своей встречи.** В карточке появилась отдельная команда отмены с уведомлением приглашенных и подтверждением перед отправкой.
- **Повторяющиеся встречи.** При создании доступны повторы каждый день, по будням, раз в неделю и раз в две недели. Окончание задается датой или числом повторений.

### Важно

Редактировать и отменять можно только встречи, которые вы организуете. Повторяющаяся серия изменяется целиком. В статистике пересекающиеся интервалы учитываются один раз при расчете занятого времени.

## Установка
- **OWA-Widget-Setup-1.1.0.exe** — установщик для Windows 10/11 x64; на ARM64 работает в эмуляции. Ставится для текущего пользователя, права администратора не нужны.
- **OWA-Widget-1.1.0-portable-x64.zip** — без установки: распакуйте в любую папку и запустите `OWA Widget.exe`. Во временные папки ничего не пишется.

## Как проверить, что файл настоящий
Установщик пока не подписан сертификатом Windows, поэтому SmartScreen может показать «Windows защитила ваш компьютер». Прежде чем нажимать «Выполнить в любом случае», сверьте файл:
- **Контрольная сумма.** В PowerShell: `Get-FileHash .\OWA-Widget-Setup-1.1.0.exe -Algorithm SHA256` — результат должен совпасть со строкой в `SHA256SUMS.txt` из этого релиза.
- **Происхождение сборки.** `gh attestation verify .\OWA-Widget-Setup-1.1.0.exe --repo dmitrbrvsk/win-owa-widget` подтверждает, что файл собран из этого репозитория workflow'ом GitHub Actions.
