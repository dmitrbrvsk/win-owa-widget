## Changes

- **The widget window releases memory.** It is created when opened and closed three minutes after being hidden. When reopened, it appears after rendering, without an empty frame.
- **The tray icon works independently of the window.** The main process now updates the countdown, pulse and tooltip. A hidden browser window no longer needs to stay open for these updates.
- **Separate ARM64 installer.** The x64 and ARM64 builds are separate: ARM computers now have `OWA-Widget-Setup-1.1.1-arm64.exe`.
- **Fewer unnecessary distribution files.** Only Russian and English Chromium language files are kept; the x64 installer no longer includes a second architecture.

### What this means

When the calendar is closed, the app keeps fewer processes running and uses less memory. The countdown and reminders continue to work in the background.

## Installation

- **OWA-Widget-Setup-1.1.1.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Installs for the current user; administrator rights are not required.
- **OWA-Widget-Setup-1.1.1-arm64.exe** — the same installer built for Windows ARM64.
- **OWA-Widget-1.1.1-portable-x64.zip** — no installation: extract to any folder and run `OWA Widget.exe`. Nothing is written to temporary folders.

## Verify the file's authenticity

The installer is not yet signed with a Windows certificate, so SmartScreen may display "Windows protected your PC". Before clicking "Run anyway", verify the file:

- **Checksum.** In PowerShell: `Get-FileHash .\OWA-Widget-Setup-1.1.1.exe -Algorithm SHA256` — the result must match the corresponding line in this release's `SHA256SUMS.txt`.
- **Build provenance.** `gh attestation verify .\OWA-Widget-Setup-1.1.1.exe --repo dmitrbrvsk/win-owa-widget` confirms that the file was built from this repository by a GitHub Actions workflow.
