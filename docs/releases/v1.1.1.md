## Что изменилось

- **Окно виджета освобождает память.** Оно создается при открытии и закрывается через три минуты после скрытия. При повторном открытии появляется после отрисовки, без пустой рамки.
- **Иконка работает независимо от окна.** Обратный отсчет, пульсацию и подсказку теперь обновляет главный процесс. Для этого больше не нужно держать скрытое окно браузера.
- **Отдельный установщик ARM64.** Сборки x64 и ARM64 разделены: для компьютеров на ARM появился файл `OWA-Widget-Setup-1.1.1-arm64.exe`.
- **Меньше лишних файлов в дистрибутиве.** Из Chromium оставлены только русские и английские языковые файлы; установщик x64 больше не включает вторую архитектуру.

### Что это дает

Когда календарь закрыт, приложение держит меньше процессов и занимает меньше памяти. Обратный отсчет и напоминания продолжают работать в фоне.

## Установка
- **OWA-Widget-Setup-1.1.1.exe** — установщик (Windows 10/11, x64; на ARM64 работает в эмуляции). Ставится для текущего пользователя, права администратора не нужны.
- **OWA-Widget-Setup-1.1.1-arm64.exe** — тот же установщик, собранный для Windows на ARM64.
- **OWA-Widget-1.1.1-portable-x64.zip** — без установки: распакуйте в любую папку и запустите `OWA Widget.exe`. Во временные папки ничего не пишется.

## Как проверить, что файл настоящий
Установщик пока не подписан сертификатом Windows, поэтому SmartScreen может показать «Windows защитила ваш компьютер». Прежде чем нажимать «Выполнить в любом случае», сверьте файл:
- **Контрольная сумма.** В PowerShell: `Get-FileHash .\OWA-Widget-Setup-1.1.1.exe -Algorithm SHA256` — результат должен совпасть со строкой в `SHA256SUMS.txt` из этого релиза.
- **Происхождение сборки.** `gh attestation verify .\OWA-Widget-Setup-1.1.1.exe --repo dmitrbrvsk/win-owa-widget` подтверждает, что файл собран из этого репозитория workflow'ом GitHub Actions.
