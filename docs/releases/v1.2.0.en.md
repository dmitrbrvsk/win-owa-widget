## Changes

- **Respond with a comment.** Add a message to the organizer when accepting, tentatively accepting or declining an invitation, up to 1000 characters.
- **Suggest another time.** Choose a new time slot and add an explanation. The organizer receives them with your invitation response.
- **Overlap warnings.** Invitations that overlap meetings you have accepted or organized are marked in the list and meeting card. You can decline a conflicting invitation from the warning.
- **Personal notes.** A "My note" field with automatic saving is available in the meeting card. Notes are visible only to you, stored encrypted on your computer and never sent to Exchange. You can delete all notes in settings.

### Important

The suggested time is sent as text in a normal invitation response. It is not an Outlook counterproposal: the meeting time in the organizer's calendar does not change automatically. Before sending a comment or time suggestion, a native confirmation dialog shows the response text.

## Installation

- **OWA-Widget-Setup-1.2.0.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Installs for the current user; administrator rights are not required.
- **OWA-Widget-Setup-1.2.0-arm64.exe** — the same installer built for Windows ARM64.
- **OWA-Widget-1.2.0-portable-x64.zip** — no installation: extract to any folder and run `OWA Widget.exe`. Nothing is written to temporary folders.

## Verify the file's authenticity

The installer is not yet signed with a Windows certificate, so SmartScreen may display "Windows protected your PC". Before clicking "Run anyway", verify the file:

- **Checksum.** In PowerShell: `Get-FileHash .\OWA-Widget-Setup-1.2.0.exe -Algorithm SHA256` — the result must match the corresponding line in this release's `SHA256SUMS.txt`.
- **Build provenance.** `gh attestation verify .\OWA-Widget-Setup-1.2.0.exe --repo dmitrbrvsk/win-owa-widget` confirms that the file was built from this repository by a GitHub Actions workflow.
