## Changes

- **Saved attendee groups.** Add colleagues in the availability window and save the group, for example "My team". Selecting a group immediately fills in the attendees and requests their availability. Groups can be renamed, edited and deleted; they are stored locally with encryption, separately for each account.
- **Privacy mode.** The lock button in the widget, settings or tray menu hides meeting titles, names, addresses and notes in every window. Times and availability remain visible. New notifications and the tray tooltip are also anonymized; the mode persists after restarting.
- **Clear connection diagnostics.** The check in settings shows four stages: server reachability, certificate acceptance, sign-in and calendar retrieval. You can see which stage failed and which stages have not been checked yet.
- **Safe support report.** In settings, view and copy the app version, connection status and technical error codes. The report excludes the server address, credentials, certificates and meeting contents. You choose whether to send it.
- **Manual update checks.** A button in settings asks GitHub for the latest stable release and offers to open its page. The request runs only when clicked, in a separate session without Exchange cookies or authorization. Downloading and installation are manual.
- **Current availability after changing attendees.** Results from an earlier request are no longer used to choose a time after the attendees or week change.

### Important

Enable privacy mode before sharing your screen: it applies inside the widget but does not clear the clipboard, Windows notification history or open system dialogs.

Checking for updates adds a separate request to GitHub only when you explicitly click the button. Calendar data and credentials still go only to the configured Exchange server.

## Installation

- **OWA-Widget-Setup-1.3.0.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Administrator rights are not required.
- **OWA-Widget-Setup-1.3.0-arm64.exe** — separate installer for Windows ARM64.
- **OWA-Widget-1.3.0-portable-x64.zip** — extract and run `OWA Widget.exe` without installation.

## Verify the files

The installer is not yet Authenticode-signed, so Windows SmartScreen may display a warning. Before running it, compare its checksum with `SHA256SUMS.txt` from this release:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.3.0.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.3.0.exe --repo dmitrbrvsk/win-owa-widget
```
