**Сохраненные группы участников, режим приватности и пошаговая диагностика подключения.**

## Что изменилось

- **Сохраненные группы участников.** Добавьте коллег в поиске свободного времени и сохраните состав, например «Моя команда». Выбор группы сразу подставляет участников и запрашивает их занятость. Группы можно переименовывать, менять и удалять; они хранятся локально с шифрованием, отдельно для каждого аккаунта.
- **Режим приватности.** Кнопка с замком в виджете, настройки или меню трея скрывают названия встреч, имена, адреса и заметки во всех окнах. Остаются время и занятость. Новые уведомления и подсказка трея также обезличены; режим сохраняется после перезапуска.
- **Понятная диагностика подключения.** Проверка в настройках показывает четыре этапа: доступность сервера, принятие сертификата, вход и получение календаря. Видно, на каком шаге произошла ошибка и какие этапы еще не проверены.
- **Безопасный отчет для поддержки.** В настройках можно скопировать и просмотреть версию приложения, состояние подключения и технические коды ошибок. Адрес сервера, учетные данные, сертификаты и содержимое встреч в отчет не входят. Отправка остается за пользователем.
- **Ручная проверка обновлений.** Кнопка в настройках запрашивает у GitHub последний стабильный релиз и предлагает открыть его страницу. Запрос выполняется только по нажатию, в отдельной сессии без cookies и авторизации Exchange. Скачивание и установка — вручную.
- **Актуальная занятость при смене участников.** Ответ на предыдущий запрос больше не используется для выбора времени после изменения состава или недели.

### Важно

Включайте приватность до демонстрации экрана: она действует в виджете, но не очищает буфер обмена, историю уведомлений Windows и открытые системные диалоги.

Проверка обновлений добавляет отдельное обращение к GitHub только по явному нажатию кнопки. Календарь и учетные данные по-прежнему передаются только настроенному серверу Exchange.

## Как проверить файлы

Установщик пока не подписан Authenticode, поэтому Windows SmartScreen может показать предупреждение. Перед запуском сверьте контрольную сумму с `SHA256SUMS.txt` из этого релиза:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.3.0.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.3.0.exe --repo dmitrbrvsk/win-owa-widget
```
