## Что изменилось

- **Календарь в отдельном окне.** Откройте пункт «Календарь…» в меню трея или нажмите кнопку разворачивания в виджете. При первом открытии окно развернуто; его можно уменьшить, изменить размер или перенести на другой монитор. Закрытие окна оставляет приложение в трее.
- **Расписание и подробности рядом.** Выберите встречу слева, чтобы увидеть участников, описание, ответы и личную заметку справа. При переходе из карточки виджета сохраняются выбранная встреча и день.
- **Переход по дням и поиск.** Выберите дату или найдите встречу через Ctrl+F. Поиск работает локально среди уже загруженных встреч; выбор даты сам по себе не загружает архив календаря с сервера.
- **Приватность и привычные действия.** В большом окне доступны создание встречи, поиск общего времени, настройки и режим приватности. При включении приватности содержимое большого окна также скрывается.
- **Обновлена среда разработки.** Проект использует Node.js 24 LTS и Yarn 4 с фиксированным lock-файлом; Windows-сборка проверяется в CI.

## Установка

- **OWA-Widget-Setup-1.4.0.exe** — установщик для Windows 10/11 x64; на ARM64 работает в эмуляции. Права администратора не нужны.
- **OWA-Widget-Setup-1.4.0-arm64.exe** — отдельный установщик для Windows ARM64.
- **OWA-Widget-1.4.0-portable-x64.zip** — распакуйте и запустите `OWA Widget.exe` без установки.

## Как проверить файлы

Установщик пока не подписан Authenticode, поэтому Windows SmartScreen может показать предупреждение. Перед запуском сверьте контрольную сумму с `SHA256SUMS.txt` из этого релиза:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.0.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.0.exe --repo dmitrbrvsk/win-owa-widget
```
