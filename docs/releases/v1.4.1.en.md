**Fixed account isolation, reauthentication and startup when local files are unavailable.**

> Archived description: version 1.4.1 was not published as a separate release; its changes were included in 1.4.2.

## Changes

- **Correct account switching.** Meetings and errors from the previous session no longer reappear after changing accounts. Old requests are cancelled and a new synchronization starts separately. Meeting cards, search results, reminders and drafts from the previous account are closed.
- **Protection against repeated failed sign-ins.** After an authorization error, requests for meeting details, invitation responses and availability also stop. Repeated clicks do not consume domain account sign-in attempts.
- **Resilient startup.** Unavailable or oversized cache and note files no longer prevent startup. If notes cannot be read, the original file is preserved and protected against overwriting until access is restored.
- **Account-bound cache.** Another account's data is not used for offline viewing. Invitation confirmation also checks that the account did not change while the native dialog was open.

### Important

After updating, the old cache without account information is fetched again from Exchange. The first schedule retrieval requires access to the server or VPN. Personal notes are not deleted.

## Installation

- **OWA-Widget-Setup-1.4.1.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Administrator rights are not required.
- **OWA-Widget-Setup-1.4.1-arm64.exe** — separate installer for Windows ARM64.
- **OWA-Widget-1.4.1-portable-x64.zip** — extract and run `OWA Widget.exe` without installation.

## Verify the files

The installer is not yet Authenticode-signed, so Windows SmartScreen may display a warning. Before running it, compare its checksum with `SHA256SUMS.txt` from this release:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.1.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.1.exe --repo dmitrbrvsk/win-owa-widget
```
