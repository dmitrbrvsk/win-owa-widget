## Changes

- **Full authorization reset when changing connections.** In addition to cookies, Chromium's separate HTTP authentication cache is cleared and the previous session's connections are closed. The new client waits for cleanup to finish before its first request.
- **Link secrets stay out of logs when a window is blocked.** If an invitation tries to open a separate window or navigate to another site, diagnostics retain only the site's origin. The path, query parameters and fragment, which may contain the meeting password, are not recorded.
- **Faster sign-in page parsing.** Repeated headers without a token no longer trigger unnecessary overlapping checks in the main process.
- **Expanded security checks.** Added tests for IPC senders, frame isolation, permissions, navigation blocking and authentication session cleanup.

## Installation

- **OWA-Widget-Setup-1.4.2.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Administrator rights are not required.
- **OWA-Widget-Setup-1.4.2-arm64.exe** — separate installer for Windows ARM64.
- **OWA-Widget-1.4.2-portable-x64.zip** — extract and run `OWA Widget.exe` without installation.

## Verify the files

The installer is not yet Authenticode-signed, so Windows SmartScreen may display a warning. Before running it, compare its checksum with `SHA256SUMS.txt` from this release:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.2.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.2.exe --repo dmitrbrvsk/win-owa-widget
```
