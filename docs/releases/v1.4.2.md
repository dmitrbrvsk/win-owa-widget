## Что изменилось

- **Полный сброс авторизации при смене подключения.** Вместе с cookies очищается отдельный кеш HTTP-авторизации Chromium и закрываются соединения прежней сессии. Новый клиент дожидается завершения очистки до первого запроса.
- **Секреты ссылок не попадают в журнал при блокировке окна.** Если приглашение пытается открыть отдельное окно или перейти на другой сайт, в диагностике остается только адрес сайта. Путь, параметры и фрагмент ссылки, где может находиться пароль встречи, не записываются.
- **Быстрее разбор страницы входа.** Повторяющиеся заголовки без токена больше не вызывают лишние перекрывающиеся проверки в основном процессе.
- **Расширены проверки безопасности.** Добавлены тесты отправителя IPC, изоляции фреймов, разрешений, блокировки навигации и очистки сессии авторизации.

## Установка

- **OWA-Widget-Setup-1.4.2.exe** — установщик для Windows 10/11 x64; на ARM64 работает в эмуляции. Права администратора не нужны.
- **OWA-Widget-Setup-1.4.2-arm64.exe** — отдельный установщик для Windows ARM64.
- **OWA-Widget-1.4.2-portable-x64.zip** — распакуйте и запустите `OWA Widget.exe` без установки.

## Как проверить файлы

Установщик пока не подписан Authenticode, поэтому Windows SmartScreen может показать предупреждение. Перед запуском сверьте контрольную сумму с `SHA256SUMS.txt` из этого релиза:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.2.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.2.exe --repo dmitrbrvsk/win-owa-widget
```
