**Closed two security control bypasses identified in the security audit.**

**Download:** [x64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.4.3/OWA-Widget-Setup-1.4.3.exe) · [ARM64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.4.3/OWA-Widget-Setup-1.4.3-arm64.exe) · [Portable](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.4.3/OWA-Widget-1.4.3-portable-x64.zip)

## Changes

- **Confirm personal meetings.** Creating, editing and cancelling a meeting now require confirmation in a native dialog even when there are no attendees. This closes a path where a compromised interface could create a calendar entry containing an external link and authorize opening it in the browser. Normal calendar links continue to work as before.
- **Clearing the cache does not authorize another sign-in.** After an incorrect password, the lock remains in place when clearing the cache, recreating the client or performing certificate operations. Connection checks also respect the lock and set it after an authorization error.
- **Retrying sign-in is a separate decision.** After an error, click "Test connection" or save corrected credentials and confirm the attempt in a native dialog. Repeated recovery prompts are limited to one per 30 seconds. This interval does not replace the domain's account lockout policy.
- **Regression checks.** Added isolated tests of the actual IPC chain: a substituted link, editing a personal meeting, sign-in recovery, declining confirmation and changing the session while a dialog is open. The tests do not contact Exchange or read a real profile.

## Installation

- **OWA-Widget-Setup-1.4.3.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Administrator rights are not required.
- **OWA-Widget-Setup-1.4.3-arm64.exe** — separate installer for Windows ARM64.
- **OWA-Widget-1.4.3-portable-x64.zip** — extract and run `OWA Widget.exe` without installation.

## Verify the files

The installer is not yet Authenticode-signed, so Windows SmartScreen may display a warning. Before running it, compare its checksum with `SHA256SUMS.txt` from this release:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.3.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.3.exe --repo dmitrbrvsk/win-owa-widget
```
