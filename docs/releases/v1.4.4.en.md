## Changes

- **A dedicated internal interface scheme.** App windows load through `owa-widget://app/`, without a local HTTP server or registering external links in Windows. Additional `file://` privileges are disabled.
- **Interface files only.** The handler serves only the single interface HTML page and bundled JS/CSS. Unrelated files, foreign hosts, write methods and directory traversal are rejected. IPC accepts only the app page.
- **Stronger packaged-app checks.** CI requires the interface to load with styles and a working preload. A running process without a functioning window is insufficient.
- **Shared release history.** The repository now includes `CHANGELOG.md` with release links and an explanation of the unpublished 1.4.1 version. A link was added to README. The English translation is [CHANGELOG.en.md](../../CHANGELOG.en.md).
- **Updated checks.** Added tests for the scheme, file restrictions and IPC origin; the manual personal-meeting scenario now requires confirmation before writing.

## Installation

- **OWA-Widget-Setup-1.4.4.exe** — installer for Windows 10/11 x64; runs on ARM64 under emulation. Administrator rights are not required.
- **OWA-Widget-Setup-1.4.4-arm64.exe** — separate installer for Windows ARM64.
- **OWA-Widget-1.4.4-portable-x64.zip** — extract and run `OWA Widget.exe` without installation.

## Verify the files

The installer is not yet Authenticode-signed, so Windows SmartScreen may display a warning. Before running it, compare its checksum with `SHA256SUMS.txt` from this release:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.4.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.4.exe --repo dmitrbrvsk/win-owa-widget
```
