## Что изменилось

- **Собственная внутренняя схема интерфейса.** Окна загружаются через `owa-widget://app/` без локального HTTP-сервера и без регистрации внешних ссылок в Windows. Дополнительные права `file://` отключены.
- **Только файлы интерфейса.** Обработчик выдает единственную HTML-страницу и собранные JS/CSS. Посторонние файлы, чужие адреса, методы записи и выход за пределы каталога отклоняются. IPC принимает только страницу приложения.
- **Усилена проверка упакованной версии.** CI требует загрузку интерфейса со стилями и рабочим preload. Запуска процесса без работающего окна недостаточно.
- **Общая история изменений.** В репозитории появился `CHANGELOG.md` со ссылками на релизы, включая пояснение отсутствия опубликованной версии 1.4.1. Ссылка добавлена в README.
- **Обновлены проверки.** Добавлены тесты схемы, файловых ограничений и источника IPC; ручной сценарий личной встречи приведен к подтверждению перед записью.

## Установка

- **OWA-Widget-Setup-1.4.4.exe** — установщик для Windows 10/11 x64; на ARM64 работает в эмуляции. Права администратора не нужны.
- **OWA-Widget-Setup-1.4.4-arm64.exe** — отдельный установщик для Windows ARM64.
- **OWA-Widget-1.4.4-portable-x64.zip** — распакуйте и запустите `OWA Widget.exe` без установки.

## Как проверить файлы

Установщик пока не подписан Authenticode, поэтому Windows SmartScreen может показать предупреждение. Перед запуском сверьте контрольную сумму с `SHA256SUMS.txt` из этого релиза:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.4.4.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.4.4.exe --repo dmitrbrvsk/win-owa-widget
```
