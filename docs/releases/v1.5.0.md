**Скачать:** [Windows x64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.5.0/OWA-Widget-Setup-1.5.0.exe) · [Windows ARM64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.5.0/OWA-Widget-Setup-1.5.0-arm64.exe) · [Portable x64](https://github.com/dmitrbrvsk/win-owa-widget/releases/download/v1.5.0/OWA-Widget-1.5.0-portable-x64.zip)

## Что изменилось

### Новые функции

- **Локальный MCP только для чтения.** Подключите локальный MCP-клиент, чтобы узнать состояние синхронизации, посмотреть загруженные встречи и их время или найти встречу по названию. Доступ по умолчанию выключен и требует системного подтверждения. Названия разрешаются отдельно; режим приватности скрывает их и блокирует поиск по ним. Смена аккаунта отзывает доступ. [Настройка и ограничения MCP](https://github.com/dmitrbrvsk/win-owa-widget/blob/v1.5.0/docs/MCP.md).
- **Восстановление старых групп и заметок.** Данные обычных ручных аккаунтов переносятся автоматически. Если прежний формат не позволяет надежно определить владельца, в настройках появляется «Восстановить для текущего аккаунта» с подтверждением в системном окне.
- **Документация на английском.** Руководство, FAQ, модель безопасности, история изменений, формы багрепорта и инструкции для разработчиков доступны на двух языках. Добавлен файл лицензии MIT, сведения о совместимости до установки и заметные ссылки на сборки.

### Безопасность и сохранность данных

- **Исправлена коллизия аккаунтов.** Windows SSO и ручной логин `windows` на одном сервере больше не разделяют владельца групп и заметок. Одни неоднозначные старые записи можно назначить только одному аккаунту.
- **Миграция сохраняет оригиналы.** Исходные файлы остаются зашифрованными. После сбоя перенос продолжает только выбранный владелец; до завершения редактирование блокируется. При совпадении заметок сохраняются текущие, одноименные группы получают номер. Непрочитанные файлы не перезаписываются.
- **Защищены подтверждения.** Смена сервера, отпечатка сертификата или аккаунта во время системного диалога отменяет устаревшее согласие. Подтверждение удаления не может удалить заметки аккаунта, на который вы переключились позже.
- **Без неожиданной смены способа входа.** Если сохраненный пароль временно недоступен, ручное подключение останавливается, а не переключается на Windows SSO под другим владельцем кеша.
- **Ограничена обработка входных данных.** Слишком сложные ответы сервера отклоняются до тяжелого разбора. Некорректные запросы MCP не расходуют лимит авторизованного клиента; медленные соединения имеют абсолютный срок. Обновлены или локально исправлены уязвимые зависимости инструментов разработки, добавлены регрессионные тесты.

### Производительность и стабильность

- **Меньше лишней работы при синхронизации.** Изменение статуса больше не копирует весь календарь во все открытые окна; форматтеры дат переиспользуются.
- **Удобнее насыщенные дни.** Очень плотное расписание и встречи на весь день показываются страницами по 50 записей с общим счетчиком. Все встречи доступны, а расчет пересечений ускорен.
- **Прокрутка остается на месте.** Обновление времени и календаря не сбрасывает ручную прокрутку занятости; смена дня и часового пояса учитывается отдельно.
- **Экраны загружаются по мере открытия.** Production JS минифицирован, неиспользуемые локали MCP исключены с сохранением валидации, браузерное демо собирается отдельно. Это уменьшает загружаемый код интерфейса, а не размер самого Electron.
- **Надежнее переход из уведомления.** Карточка встречи открывается после готовности интерфейса, в том числе при первом открытии окна.

### Важно при обновлении

- **Календарь синхронизируется повторно.** Старый кеш не назначается новому ключу аккаунта. Сохраненное разрешение MCP под старым ключом тоже не восстанавливается: при необходимости подтвердите доступ заново.
- **Проверьте аккаунт перед восстановлением.** Убедитесь, что выбраны правильные сервер и способ входа. Отмена ничего не переносит. Более старый файл `notes.bin` без владельца остается отдельно и не импортируется. Не удаляйте исходные файлы или журнал миграции и не прикладывайте их к багрепортам. [Как устроен перенос](https://github.com/dmitrbrvsk/win-owa-widget/blob/v1.5.0/docs/GUIDE.md#перенос-данных-старых-аккаунтов).
- **MCP подключается отдельно.** Для адаптера нужен Node.js 24.22+ в ветке 24.x; для обычной работы виджета устанавливать Node.js не требуется. MCP видит только уже загруженные встречи, поэтому пустой ответ не доказывает свободное время. Запись в календарь, участники, описания, ссылки, заметки и учетные данные через MCP недоступны. Подключенный ИИ-клиент может передать разрешенные данные своему провайдеру — учитывайте правила компании.

## Установка

- **OWA-Widget-Setup-1.5.0.exe** — установщик для Windows 10/11 x64; на ARM64 работает в эмуляции. Права администратора не нужны.
- **OWA-Widget-Setup-1.5.0-arm64.exe** — установщик для Windows ARM64.
- **OWA-Widget-1.5.0-portable-x64.zip** — распакуйте и запустите `OWA Widget.exe` без установки.

## Как проверить файлы

Установщик пока не подписан Authenticode, поэтому Windows SmartScreen может показать предупреждение. Перед запуском сверьте контрольную сумму с `SHA256SUMS.txt` из этого релиза. Для проверки происхождения сборки используйте GitHub CLI:

```powershell
Get-FileHash .\OWA-Widget-Setup-1.5.0.exe -Algorithm SHA256
gh attestation verify .\OWA-Widget-Setup-1.5.0.exe --repo dmitrbrvsk/win-owa-widget
```
